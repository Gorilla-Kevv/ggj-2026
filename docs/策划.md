> 版本：v1.0
> 最后更新：2026年8月1日
> 开发周期：14天
> 引擎：Godot 4.6

## 一、游戏概述

**游戏名称：** 风语者 (Wind Whisper)

**一句话描述：** 你是一株逃离实验室的风滚草，用风的力量穿越重重机关，追寻自由。

**游戏类型：** 2D横版风控解谜闯关（含Boss战要素）

**目标平台：** PC (Windows)

**核心体验：** 玩家以鼠标指针为风源，通过按住/点按左键吹出不同强度的风，操控主角风滚草和场景中的可交互物体，穿越机关重重的关卡。全程悬空、触底即死，能量有限，每一步都需要策略。

**参考风格：** 《空洞骑士》唯美手绘风 × 《Baba Is You》式的机制解谜思维

## 二、叙事背景

一家秘密实验室将一株普通的风滚草注入"风之精华"，赋予它悬浮于空中的能力，以及召唤风的力量。实验体代号"W-01"在一次意外中苏醒，发现自己被困在玻璃罩中。它呼唤微风，吹开了罩子。

逃亡就此开始。

**三幕结构：**

| 幕 | 关卡 | 主题 |
|----|------|------|
| 第一幕：困兽 | 第1-2关 | 实验室内的觉醒与逃亡 |
| 第二幕：荒野 | 第3-4关 | 外部世界的探索与求生 |
| 第三幕：归宿 | 第5关 | 最终决战，赢取自由 |

## 三、核心玩法机制

### 3.1 操作总览

| 操作 | 效果 |
|------|------|
| R键 | 循环切换作用目标（默认主角 → 可交互物体 → 主角...） |
| 鼠标移动 | 鼠标与选中物体间显示半透明风向连线（风从鼠标吹向物体） |
| 按住左键 | 持续吹风，风力强度=按住时长（上限约3秒达最大风力） |
| 松开左键 | 停止吹风 |
| 短点左键 | 一股短促微风，用于精确微调位移 |

### 3.2 风的方向逻辑

- 鼠标指针是**风源**，风从指针位置向外吹
- 选中谁，谁就被吹
- 半透明连线指示风向，线密度/流动速度表示当前风力强度
- 示例：
  - 鼠标在主角左上方按住 → 风从左上吹向右下，主角被吹向右下方
  - 选中箱子，鼠标在箱子右侧按住 → 风从右吹向左，箱子被推向左侧

### 3.3 目标切换（R键）

| 目标 | 说明 |
|------|------|
| 主角（默认） | 风滚草自身，最常用的吹送目标 |
| 可交互物体 | 箱子、平台、机关开关、风化岩石等 |

**选中反馈：**
- 选中物体：金色高亮描边 + 轻微脉动
- 鼠标与选中物体间：半透明白色虚线风向连线，带淡蓝光晕
- 吹风时：沿风向线显示气流粒子流动（密度/速度=风力强度）

### 3.4 能量系统

| 参数 | 数值 |
|------|------|
| 能量上限 | 100点 |
| 吹风消耗 | 约20点/秒（满能量可持续吹风5秒） |
| 自动回复 | 约15点/秒（约7秒从空到满） |
| 能量耗尽表现 | HUD能量条闪烁红色警告，短促"嗡嗡"提示音 |

策略意义：不能无脑狂吹，需规划吹风节奏。短点吹省能量（用于微调），长按适合冲刺或吹动重物。

### 3.5 主角物理

| 属性 | 设定 |
|------|------|
| 重力 | 正常的30%，模拟轻盈飘浮感 |
| 移动方式 | 全程悬浮，触底即死 |
| 碰撞体积 | 圆形，直径约40px |
| 惯性 | 停止吹风后有轻微惯性漂移（摩擦系数约0.95） |
| 最大速度 | 约600px/s（被狂风吹送时） |

**死亡条件：**
- 触碰地面、尖刺、毒池
- 被敌人碰到
- 落入深渊（无底边界）

### 3.6 死亡与重生

- 死亡后从最近激活的检查点重生
- 检查点：绿色光柱，触碰即激活
- 重生后能量条回满
- 死亡表现：沉闷的"砰"声+风声骤停+屏幕边缘暗红色晕影

### 3.7 风与场景交互

| 交互类型 | 示例 | 出现关卡 |
|----------|------|----------|
| 吹移障碍物 | 吹开挡路箱子、推动平台 | 全关卡 |
| 触发机关 | 吹动风扇叶片→开门、吹转阀门 | 第1、3、4关 |
| 风道折射 | 风吹入管道从另一端折射出来 | 第2关 |
| 吹倒/吹落物体 | 吹倒岩柱搭桥、吹落悬挂物 | 第3、5关 |
| 连锁机关 | 吹风扇→通电→齿轮转动→平台升降 | 第4关 |

## 四、关卡设计

### 4.1 关卡总览

| 关卡 | 名称 | 场景 | 新机制 | 敌人 | 预估时长 |
|------|------|------|--------|------|----------|
| 1 | 觉醒·玻璃罩 | 实验室测试区 | 基础操作全教学 | 无 | 2-3分钟 |
| 2 | 逃亡·通风管道 | 通风系统 | 风道折射、躲避追捕 | 巡逻研究员 | 4-6分钟 |
| 3 | 荒原·炽风峡谷 | 荒漠峡谷 | 热气流、沙瀑、风化岩 | 追踪无人机、岩栖蝎 | 6-8分钟 |
| 4 | 上升·风之草原 | 金色草原 | 自然风带、蒲公英气流、风车连锁 | 猎风鹰、无人机母舰 | 7-10分钟 |
| 5 | 归宿·飓风之眼 | 暴风塔内部 | Boss战：三重风态循环 | Boss捕风者 | 4-6分钟 |

### 4.2 第1关：觉醒·玻璃罩

**场景：** 冷白色调的实验室基础测试区。玻璃器皿、仪表盘、荧光灯管。

**叙事：** 风滚草W-01在玻璃罩中苏醒，发现体内涌动着风的力量。

**流程：**
1. 封闭玻璃罩内出生 — 提示"按R选中自己，移动鼠标看风向线"
2. 按住左键吹开罩顶 — 飞出
3. 短点微调穿过窄缝 — 学习微风精确控制
4. R切换选中挡路小箱子 — 吹开通过
5. 惯性滑行漂过间隙 — 学习不吹风时的漂移
6. 发现通风管道入口 — 过关

**教学覆盖：** 全部基础操作（吹自己、微调、切换目标、惯性滑行）

### 4.3 第2关：逃亡·通风管道

**场景：** 暗灰金属管道网络。红色警报灯闪烁，探照灯光柱扫过。

**叙事：** 警报拉响，研究员开始追捕。必须穿过管道逃出实验室。

**新机制：**
- **风道折射** — 风吹到管道内壁沿管道路径自动偏转反弹
- **巡逻研究员** — 地面走廊持探照灯，被发现后追击，碰到即死

**流程：**
1. 进入狭窄管道系统，空间限制移动
2. 学习风道折射：风吹墙→沿管道走势偏转
3. 研究员出现 — 吹落管道上方挡板砸晕研究员
4. 多层管道分支，选对路径通往出口
5. 吹开末端铁栅栏 — 阳光照入 — 冲出管道

**核心体验：** 管道约束移动 + 躲避追捕的紧张感

### 4.4 第3关：荒原·炽风峡谷

**场景：** 赤色岩壁、风化蘑菇石、干燥热浪扭曲空气。沙漠峡谷地貌。

**叙事：** 逃出实验室，但世界并非温柔。实验室的追踪无人机紧随其后。风滚草穿越灼热峡谷，寻找传说中的风之草原。

**新机制：**

| 机制 | 说明 |
|------|------|
| 热力上升气流 | 峡谷中固定位置有扭动的热浪柱，主角进入自动上浮，不耗能量 |
| 沙瀑 | 间歇性从崖壁倾泻的流沙，触碰往下推。可用风吹散短暂打开通路 |
| 风化岩石 | 脆弱的岩柱，吹倒后可搭桥或砸中下方敌人 |

**敌人：**
- **追踪无人机 ×2** — 从实验室追出的，峡谷中巡逻扫描，发现后加速冲撞
- **岩栖蝎** — 伏在岩壁上，玩家靠近时弹射扑击，可用风吹偏

**流程：**
1. 从管道跌入峡谷底部 — 首次面对开阔户外空间
2. 利用上升热气流攀升到高处平台
3. 无人机出现 — 切换选中风化岩石→吹倒砸落无人机
4. 沙瀑挡路 — 等间歇期或吹散通过
5. 峡谷窄道同时应对岩栖蝎+无人机 — 利用热气流快速脱离
6. 吹倒最后一根巨大岩柱搭桥跨越深渊 — 进入草原

**核心体验：** 户外开阔感 + 多敌人同时处理 + 环境机制利用

### 4.5 第4关：上升·风之草原

**场景：** 一望无际的金色草原，草浪随风起伏。巨大风车遗迹矗立，天空中飘浮蒲公英和飞鸟。

**叙事：** 进入草原，这里似乎是风滚草的故乡。古老的风车遗迹暗示曾有文明在此驭风。但实验室的追兵已先一步布下封锁。

**新机制：**

| 机制 | 说明 |
|------|------|
| 自然风向带 | 草原中有固定水平风带（视觉：草浪流动方向），顺风滑翔省能量+加速，逆风对抗加倍耗能+减速 |
| 蒲公英上升气流 | 大簇蒲公英被惊扰后释放飞絮，形成短暂上升气流柱 |
| 风车机关 | 古风车遗迹，吹动叶片→齿轮转动→升起/降下远处平台。多风车可形成连锁机关 |

**敌人：**
- **猎风鹰** — 盘旋高空，俯冲抓击。需预判轨迹用风吹偏自己躲避
- **封锁无人机母舰** — 实验室重型无人机，草原中心巡逻，释放小型追踪弹。需利用风车打开通道绕过

**流程：**
1. 进入草原 — 顺自然风带滑翔，感受速度与自由
2. 猎风鹰出现 — 学习在风带+自身吹风双作用力下机动躲避
3. 第一座风车 — 吹动叶片升起远方平台
4. 蒲公英区域 — 惊扰蒲公英乘上升气流到达高处
5. 双风车连锁谜题 — 选中一个吹→惯性滑到第二个→继续吹，解锁草原深处大门
6. 母舰封锁区 — 利用风车升起掩体平台逐段推进，从母舰上方掠过
7. 草原尽头 — 巨大暴风塔矗立 — 第5关入口

**核心体验：** 自然风带的利用与对抗 + 多风车连锁解谜

### 4.6 第5关（Boss）：归宿·飓风之眼

**场景：** 远古暴风塔内部。塔心是永不停歇的巨大风穴，巨石废墟悬浮在飓风中。

**叙事：** 这里是风的源头，也是风滚草的归宿。击败实验室的最终兵器——「捕风者」巨型机甲，真正的自由就在飓风之眼上空。

**Boss：捕风者（Windcatcher）**

巨型四臂机甲，每只手臂末端有涡轮风扇，能制造和操控风场。

**Boss机制 — 三重风态循环：**

| 阶段 | 持续 | 机制 |
|------|------|------|
| 吸气态 | 6秒 | Boss四涡轮向内吸气，全屏物体（含主角）被拉向Boss。玩家必须向外吹风抵抗拉力。场景中碎石被吸入 — 选中碎石吹向Boss涡轮可卡住它 |
| 暴风态 | 5秒 | Boss向外爆发飓风，主角被高速推向外围。墙上尖刺密布，需上下微调躲避。此阶段主角获得**接触伤害**能力，可撞向Boss核心（暴露的红色能量球） |
| 平静态 | 7秒 | Boss涡轮过载冷却，无法制造风。场景碎石、残骸可被玩家自由吹向Boss造成伤害 |

**战斗阶段：**
1. **P1（100%-66%）** — 吸气态卡涡轮 → 暴风态撞击核心
2. **P2（66%-33%）** — Boss增加弹幕（压缩风刃），平静态缩短为5秒
3. **P3（33%-0%）** — 三态切换加速，核心暴露时间更短。最后一击需在暴风态中同时吹飞四块巨石命中核心
4. **终结演出** — Boss爆炸，飓风塔崩塌。风滚草被最后的上升气流托起，冲出塔顶。蓝天白云，金色草原在脚下展开。自由。

**核心体验：** 所有机制的综合运用 + 史诗对决

### 4.7 关卡节奏曲线

```
关1（学）  →  关2（逃）  →  关3（斗）  →  关4（解）  →  关5（战）
引导宽松    管道紧张     峡谷对抗     草原策略     飓风爆发
```

## 五、美术与音频

### 5.1 美术风格

**主方向：** 类《空洞骑士》唯美手绘风格 — 手绘感线条、精致渐变上色、光影氛围浓厚。

**风滚草主角设计：**
- 外形：藤蔓交错缠绕的球形，直径约40px
- 配色：枯黄+墨绿藤蔓交织，中心隐约透出淡蓝色风之精华微光
- 动画：持续缓慢旋转，吹风时加速旋转+表面藤蔓飘散碎叶粒子
- 情绪表达：无五官，通过旋转速度、抖动、光晕变化传达状态

**场景色调：**

| 关卡 | 色调 | 核心视觉元素 |
|------|------|-------------|
| 1 玻璃罩 | 冷白+蓝灰 | 无菌实验室、玻璃反光、仪表盘、荧光灯管 |
| 2 通风管道 | 暗灰+金属银 | 交错管道、铁栅栏、红色警报灯、探照灯光柱 |
| 3 炽风峡谷 | 橙红+土黄 | 赤色岩壁、热浪扭曲效果、风化蘑菇石、流沙瀑布 |
| 4 风之草原 | 金黄+天蓝 | 草浪动态摇曳、风车遗迹、蒲公英飞絮、浮云投影 |
| 5 飓风之眼 | 深灰+青蓝 | 旋转暴风粒子、巨石废墟、蓝色能量电弧、涡轮火光 |

**风效视觉体系：**
- 风向线：鼠标与目标间半透明白色虚线，带淡蓝光晕
- 吹风粒子：沿风向线流动的气流粒子（密度/速度=风力强度）
- 选中物体高亮：金色描边 + 轻微脉动
- 自然风带：草浪流动方向 + 半透明气流带
- 热力上升气流：扭动的透明热浪折射效果

**UI/HUD：**
- 左上角：弧形能量条（青蓝色填充，类似风力计），下方显示当前选中目标名称
- 死亡提示：屏幕边缘淡入暗红色晕影
- 检查点激活：绿色光柱从地面升起
- Boss血条：顶部居中，红色粗条+金色边框

### 5.2 音频

| 类别 | 说明 |
|------|------|
| 背景音乐 | 以风笛、木管、轻弦乐为主。实验室章节冷峻电子+环境音，户外章节温暖管弦+民谣感 |
| 吹风音效 | 根据风力强度分层混音 — 微风轻柔"呼"，狂风低沉"呜" |
| 环境音 | 实验室（机器嗡鸣、警报）、峡谷（风声呼啸、沙砾滑落）、草原（草浪沙沙、鹰啸、风车吱嘎）、飓风塔（沉重低频轰鸣） |
| UI音效 | 选目标切换（清亮"叮"）、能量耗尽警告（短促"嗡嗡"）、死亡（沉闷"砰"+风声骤停）、检查点（柔和上升音阶） |
| 敌人音效 | 无人机（螺旋桨嗡鸣由远及近）、研究员脚步声+对讲机杂音、猎风鹰俯冲尖啸 |

**音频来源：** 大部分音效可从免费音效库获取，背景音乐可借助AI工具生成适配各关卡氛围。
